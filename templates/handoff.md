## Goal
One paragraph. What exists when v1.0 is done.

## What to read
Every document the agent needs, one line each on what it is for. Read them in this repo; nothing is copied into the code repository.

## Reading order
What to read first, and what to read only when working on the part it covers.

## Shared constraints
Stack, conventions, repository, and anything the ADRs mandate. These apply to everything you build.

## What to do first
Write an implementation plan and roadmap and get Mike's approval. Then build one milestone at a time.

## When to stop and ask
If a document is ambiguous, or two documents contradict each other, stop and ask Mike rather than guessing: open an issue in this repo with the `question` label. Do not edit these documents.
